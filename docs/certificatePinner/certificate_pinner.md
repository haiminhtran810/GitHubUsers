## Security with network protocols

Client-server encrypted interaction use TLS (Transport Layer Security) to protect your app`s data. TLS is a security protocol used to encrypt data transmitted between a client and a server over the Internet. It provides three key security:

1. Confidentiality: Ensures that data is encrypted, so no one can read it while it is being transmitted
2. Integrity: Ensures that the data can not be altered or tampered with during transmission
3. Authentication: Ensures that the client is communicating with the real server
